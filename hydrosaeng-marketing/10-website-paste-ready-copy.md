# Paste-Ready Website Fixes (Day 1)

Exact before → after strings. Open the page in Lovable, find the left text, replace with
the right text. This clears the FTC/FDA exposure and the worst trust leaks in ~15 min.

## "See The Difference" before/after
- Caption "Softer fine lines, firmer, lifted skin." → **"Softer-looking fine lines, firmer, more defined skin."** (drop "lifted")
- Heading "Unretouched before & after — visible change you can feel." → if these are NOT real
  results from this exact product, change to **"Before & after — the glow-up we're going for."**
  (Keep "Unretouched" ONLY if every image is a genuine result you can prove.)

## Variant label bugs (Shopify/Lovable)
- Serum: variant group labeled **"NET WT"** → rename to **"Type"** (options are Salmon DNA / Rose PDRN)
- Mask: variant group labeled **"COLOR"** → rename to **"Size"** (options are 1 Box-4 Pack / 2 Box-8 Pack)

## "4.9★" rating
Either add a real review count + 2–3 real review quotes, or remove the star number until you
have them. A rating with no reviews behind it reads as fake and costs more trust than it earns.
